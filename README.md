# 图灵鉴X · 双十一专鉴有礼 Demo

基于原鉴定与卡牌活动工程改版的可交互 Web Demo。专家首页与 AI 鉴美妆后的专鉴卡片共用累计进度、发券、扭蛋和排行榜；抽奖中心同时承载本次专鉴活动、卡牌第一期历史记录和下一期待开启状态。

本项目用于体验完整流程。AI 结果、专家订单、发券、中奖、库存及榜单均为模拟，不连接真实鉴定、支付或奖品发放服务。

## 本地运行与部署

需要 Node.js 22 或以上，无需安装第三方依赖。

```bash
npm run dev -- --host 127.0.0.1 --port 4181
```

通过 HTTP 打开 `http://127.0.0.1:4181/`。也可直接运行：

```bash
node scripts/serve.mjs --host 127.0.0.1 --port 4181
```

测试、构建及构建后预览：

```bash
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4182
```

构建输出为 `dist/`，可部署到静态服务器。页面使用 hash 路由，静态服务根目录需指向完整的 `dist/`，保留其中的 HTML、JavaScript、CSS 与图片相对路径。构建仅替换属于本项目的已生成输出，遇到无构建清单或夹杂其他文件的输出目录会停止。

页面与资源均在项目内，无外部 CDN 依赖。不要使用 `file://` 双击打开页面。部署成功只表示 Web Demo 可访问，不等于微信小程序原生上线或真实运营系统已接通。

## 页面与完整体验路径

| 入口 | 当前功能 |
| --- | --- |
| `/#home` | AI 技能轮播、图片本地预览、咨询演示；中奖播报点击后定位专家首页扭蛋机；鉴美妆进入模拟 AI 结果与专鉴转化卡片 |
| `/#expert` | 紧凑免费专鉴入口＋鲜艳立体扭蛋机，同屏展示；点击进入选券/抽奖/完整进度大弹层；保留 28 个品类选择与共享流程 |
| `/#card` | 保留卡牌上传、选款与 AI 结果演示；专鉴可进入共同传图流程；旧卡牌活动已结束，下一期未开启 |
| `/#lottery` | 先选活动和券种，再单抽或同券五连抽；未使用/已使用/已过期券、获得记录、完整抽奖记录、奖池与规则 |
| `/#prizes` | 按活动展示实物与鉴定券，标明普通/高级券来源；本次实物收货信息填写、校验、修改；旧期奖品与原期限展示 |
| `/#ranking` | 鉴真王者/避雷王者切换、前三领奖台、前 100 名与本人排名、规则及奖励 |

三个页面模块由同站点路由壳承载：`home.html`、`card.html`、`activity.html`。已加载模块在切换后保留；新建对话不会清空活动权益与历史。

**专家首页路径：** 免费扭蛋体验 → 去专鉴 → 选择品类、品牌与款式 → 五点位传图占位页 → 提交专家评估 → 报告与进度弹窗 → 抽奖中心或排行榜。

**AI 转专鉴路径：** 选择鉴美妆 → 模拟 AI 结果 → 限时免费专鉴卡片与当前进度 → 带入产品进入同一传图页 → 同一提交、报告、进度和抽奖流程。

传图与报告内容采用固定占位。提交成功会真实更新当前 Demo 的订单、累计次数和券余额；报告中的“演示：生成专家结果”可选择鉴真、鉴假或无法判断，验证排行榜联动。

## 本次专鉴活动规则

### 时间与参与范围

- 北京时间 **2026 年 10 月 27 日 00:00 起，至 2026 年 11 月 11 日 00:00 止**，结束时刻不包含在活动内。即 11 月 10 日结束后关闭，11 月 11 日当天已不能参与。
- 活动期间全部用户、全部品类可免费专鉴。
- **只有美妆、包袋、鞋靴、服饰、手表、数码 3C** 参与本次活动计次、发券和排行榜。
- 卡牌及其他品类不计入本次活动，不发本次抽奖券，不出现本次进度奖励弹窗。AI 鉴定本身不计本活动次数。

### 提交、发券与有效期

| 事项 | 规则 |
| --- | --- |
| 计次时点 | 活动参与品类的专家订单提交成功即累计 1 单，后续结果不回退进度 |
| 普通里程碑 | 第 2、4、6、8、12、14……单各发 1 张普通抽奖券 |
| 高级里程碑 | 第 10、20、30……单各发 1 张高级抽奖券，该节点不同时发普通券 |
| 累计周期 | 跨天累计、无计次和发券上限；进度保留真实累计单数，可回滑历史里程碑 |
| 每日赠券 | 每天首次进入活动自动获得 1 张普通抽奖券，当天有效，未使用不顺延 |
| 其他抽奖券 | 通过鉴定获得的普通券、高级券在活动结束时统一失效 |
| 消耗顺序 | 优先消耗即将到期的券，再按到账时间处理 |
| 抽取方式 | 单次使用 1 张或五次使用 5 张同种券，不跨券种或活动混用 |
| 抽中的鉴定券 | 每张代表 1 次免费专鉴，有效至 **2026 年 12 月 12 日 23:59:59**；真实核销后续接入 |

内部体验规则：固定“再接再厉”仅绑定首次免费引导对应的那一张普通赠券；不影响其他普通券、高级券及后续每日赠券。用户界面不提前披露该固定结果，抽取后按正常结果展示。

单抽与五连抽复用同一扭蛋机，搅动幅度、出球节奏与时长不同，五枚一起揭晓。普通里程碑使用紫色奖励效果，高级里程碑使用暖金效果。支持跳过抽奖动画和系统“减少动态效果”；动画不重复扣券或重复发放结果。

### 奖池与库存

| 奖池 | 实物奖品 | 实物合计概率 | 鉴定券 | 再接再厉 |
| --- | --- | ---: | ---: | ---: |
| 高级 | YSL 气垫、COACH 腰带、雷蛇耳机、COACH 钱包，各 1 份活动总库存 | 5% | 75% | 20% |
| 普通 | 美妆小样、护肤品小样、香水小样；具体规格与数量待确认 | 8% | 72% | 20% |

同池仍有库存的实物奖品等概率分配。某款库存为 0 后不再抽出；实物全部抽完，或该用户已中过实物时，原实物概率全部转为鉴定券，变为鉴定券 80%、再接再厉 20%。

同一用户在本次专鉴活动的普通、高级奖池中**合计最多中一次实物**，与卡牌活动独立。普通池中了小样后，高级池也不会再中实物。完整抽奖记录保留“再接再厉”，但它不计入奖品数量。

Demo 的库存保存在当前浏览器，高级各 1 份用于演示扣减；普通池 `quantity: null` 表示数量待配置，并非已确认无限库存。真实全体用户共享库存、中奖资格和原子扣减须由服务端负责。

### 排行榜

- 仅统计活动期间六类参与品类的专家最终结果；待鉴定、无法判断及活动结束后才出具的结果不计入。
- 鉴真王者按鉴真单数，避雷王者按鉴假单数；同数时先达到该单数的用户优先。
- 展示前 100 名、前三领奖台及本人排名；公开用户名脱敏。Demo 榜单含标识明确的演示用户，本人的排名随模拟结果变化。
- 活动结束统一结算。鉴真榜前三名每人获得称号和 200 元现金红包；避雷榜前三名每人获得称号和不限品类、次数的终身免费专鉴权益。
- 同一用户可同时获得两榜奖励。现金/权益领取、实物领奖截止与发货规则待补充，Demo 不执行真实发放。

## 卡牌旧期与下一期

卡牌第一期为 **2026 年 9 月 25 日至 10 月 8 日 00:00**，当前已结束；下一期尚未开始。本次不重开旧期，不为下一期提前发券或允许抽奖。

抽奖中心直接读取已有 `jianx-card-preview-v1` 会话中的 `state`，按原有 `welcome`、`ledger`、`draws`、`vouchers`、`addresses` 结构展示。中心不迁移、覆盖或重写这个存储键：

- 未使用的第一期抽奖券显示已过期；已使用部分保留使用记录。
- 原鉴定券保留原始到期时间与使用状态，不改成新活动的 12 月 12 日期限。
- 实物奖品、中奖来源与已有收货信息继续展示；第一期展示页面只读。
- 没有旧数据时显示明确标识的第一期演示记录；示例不写入旧存储键。
- 下一期只显示未开启状态及原有新人五连抽、鉴定赠券、分享/邀请机制的入口说明，具体开放时间以后续配置为准。

旧卡牌规则与页面模块仍留在源码中，用于后续独立活动接续，不能直接用旧存储键开启新一期运营数据。

## 演示控制与数据

专家首页底部的“模拟场景”提供六组共 23 个入口，支持“重播当前场景”和“恢复初始状态”：

| 场景 | 用途 |
| --- | --- |
| 新手体验 | 首次免费引导、今日免费券已用完、次日重新领取及昨日过期提醒 |
| 累计进度 | 1、2、9、10、14、20、50 单；直接展示发券动效，支持回看历史节点 |
| 抽奖效果 | 普通/高级券，单次/五次，自然随机、实物、鉴定券、再接再厉、五连混合结果 |
| 特殊状态 | 券不足、已中过实物、实物售罄、非活动品类、未开始、已结束 |
| 排行榜 | 未上榜、榜内普通名次、前三名、双榜同时前三 |
| 卡牌活动 | 第一期历史记录、下一期待开启 |

默认演示时间为 **2026 年 10 月 27 日 10:00，北京时间**，随实际经过的时间推进；它不是访问者设备的真实日历。每次选择专鉴场景都会从独立固定样本重建当前 Demo，便于重复展示。指定抽奖结果仅通过该次调用的随机函数实现，正常抽奖仍遵循原概率；首次免费引导券规则保持不变。卡牌场景只切换页面，不重置专鉴状态或旧卡牌存储。

新活动使用独立的 `localStorage` 键 `jianx-expert-event-2026-v1`，由订单、票券批次、抽奖批次、鉴定券、地址、库存和演示时钟组成。相同域名中的页面共享并同步；不同部署域名、不同浏览器或设备不会自动迁移。存储不可用时降级为当前页面内存状态。
