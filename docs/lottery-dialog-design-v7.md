# 双11抽奖弹窗规范 · v7

本轮实现方案，依据图灵鉴X设计 Skill 与本轮明确要求制定。活动弹层统一使用以下规则；原卡牌页面、顶部导航及专家介绍保留。

## 视觉

- 底色用有色相的深靛 `#24215a` 至 `#302465`，顶部局部淡紫柔光；不用纯黑、灰色面板或厚重双边框。
- 弹层圆角 24 px，单层 1 px 半透明淡紫描边、顶部内高光。遮罩为半透明深靛，轻模糊。
- 标题 20–24 px，主文字 `#f5f0ff`，正文 `#cfc2ed`。一个弹窗只保留一个主标题；规则、有效期、结果数量等必要信息不删除。
- 普通奖励用清透淡紫券图，高级奖励用同系列香槟券图。实物使用已有商品图；鉴定券继续复用原「专家线上鉴别券」组件。
- 主按钮沿用蓝紫品牌渐变，高 48 px；次按钮透明靛紫底、细描边。每处只强调一个主操作，关闭热区至少 44 px。
- 不叠加「已到账」「已解锁」「好礼抵达」等同义文案。不重复展示规则，不以宣传句占用奖励主体空间。

## 弹窗类型

- 免费引导：普通券图、一个主标题、「今日有效」及免费扭一次。
- 提交发券：券图与 +1、普通/高级抽奖券名称、轻量累计进度、去抽奖中心、王者榜入口。
- 未到里程碑：实际累计进度，不展示发券图或庆祝效果。
- 抽奖操作：选券、机台、单抽/五连抽、必要有效期、累计进度。
- 开奖：实物优先呈现，鉴定券沿用既有票券组件，五连抽保留每个结果；中奖统一引导「我的奖品」管理。
- 规则与明细：同一套弹层底色、标题和按钮；保留可滚动的必要规则和记录。

## 动效

| 场景 | 表现 |
| --- | --- |
| 普通抽奖券到账 | 紫色、淡紫短彩带，轻量光点，券图柔和进入 |
| 高级抽奖券到账 | 香槟金烟花、弧线丝带与分层柔光，节奏更舒展 |
| 抽中鉴定券 | 轻盈紫色庆祝与柔光 |
| 抽中实物 | 金紫烟花与更丰富彩带，商品居中 |
| 未中奖 | 胶囊轻微出现与少量光点，无中奖烟花 |

动画不阻塞按钮，不改变发券、扣券或保存次数；关闭、切换、重复打开均清理动画。减少动态效果设置下去除粒子及位移动画。
