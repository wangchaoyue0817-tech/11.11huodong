# 专鉴扭蛋活动奖品素材

## 来源与用途

`public/assets/gacha/prizes-sheet.png` 由本次任务使用 **Codex 内置 ImageGen** 生成，用于 Web Demo 的扭蛋球内奖品、机台展示窗、抽奖结果、奖池与“我的奖品”。这是一张 4 列 × 2 行的透明 PNG，当前文件尺寸为 **1774 × 887 px**，RGBA 格式。

图片是代表性产品视觉，不是品牌官方商品图，也不代表已确认发放的具体型号、色号、容量、规格或包装。YSL 气垫、COACH 腰带与钱包、雷蛇耳机的名称来自活动奖品清单；普通小样的具体规格仍待确认。

生成提示摘要：为深靛、蓝紫、少量暖金的精致扭蛋活动制作统一光照、独立留白的高质量商品图；透明背景，严格 4×2 排列，物件互不重叠；依次展示黑金气垫盒、皮革腰带、耳机、皮革钱包、美妆软管小样、护肤滴管瓶、香水瓶，以及紫色专家鉴定券。强调细腻材质、干净轮廓与可识别的小尺寸展示。这是提示概括，不是逐字原始 prompt。

## 复用与替换

所有新活动页面通过 `public/capsule-machine.js` 的 `prizeArt(id, {className})` 取得统一素材标记。该函数将模型奖品 ID 映射到图集位置；`public/capsule-machine.css` 控制图集裁切、容器比例和 SVG 回退。

同目录中的 `ysl.svg`、`c-belt.svg`、`razer.svg`、`c-wallet.svg`、`makeup.svg`、`skincare.svg`、`perfume.svg`、`voucher.svg` 为对应的矢量回退素材，`none.svg` 用于未中奖状态。其图形为项目内的代表性示意。

后续替换为确定 SKU 的正式商品素材时：

1. 保留模型奖品 ID，使库存、抽奖结果与历史奖品记录继续对应同一项。
2. 若沿用图集，保持上述 4×2 顺序、每格相同尺寸、透明背景、物件四周留白；不要让阴影或商品越过格位边界。
3. 若改为单张素材，统一修改 `prizeArt` 及其样式映射，避免首页、结果页与奖品列表出现不同商品图。
4. 核对移动端球内小图与奖池大图，确保主体完整、比例一致，图形不会被圆角或图集边界截断。
5. 实际商品名称、规格与图片同时更新；图像替换本身不会更改概率或库存规则。

实物中奖总概率、可用库存和每用户最多一次实物限制由 `expert-event-model.js` 管理，图片不参与中奖判断。当前生成素材用于 Demo 展示，真实发放以最终确定的商品资料为准。
