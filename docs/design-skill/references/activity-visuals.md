# 活动视觉：品牌连续、现代材质

适用于图灵鉴X的抽奖装置、活动入口、奖励反馈与里程碑。来源：用户2026-10-20针对专鉴扭蛋活动的多轮纠正，以当日最新要求为准。深靛、蓝紫承担统一产品语境，活动主体用现代材质和局部亮色建立吸引力；具体页面结构见 [最新活动基线](product-baseline.md)。

## 色彩与材质

- 用户明确否定上一版瓷白、冰蓝、宝蓝机台与深靛专家页的拼接效果。参考机台的圆润形体、清透玻璃和现代材质可以借鉴，参考图的蓝色配色不能直接作为品牌规范。
- 本次改版保持简单形体、连续圆角、统一光源和接触阴影；机身与球舱应带有同页蓝紫光谱的环境色。浅色材质可以用于提高辨识度，但不能形成突兀的大块冷白与青蓝底。淡紫缎面陶瓷、通透紫晶玻璃是当前实现方向，尚不代表用户已认可具体素材。
- 亮紫、玫紫和少量暖金用于奖品、彩球或权益点缀；主要操作沿用现有品牌蓝紫渐变。鲜艳通过清晰亮暗和局部色彩体现，不能用整卡高饱和渐变、厚重彩色阴影或大面积粉蓝塑料感代替质感。
- 历史活动色变量只作为可选局部点缀，不要求每次全部使用。实际合成截图的品牌一致性优先于孤立素材的鲜艳度。
- 高级感来自材质细节、比例与留白。本次机台不使用宝石镶嵌、羽翼、复古机甲、繁复金属边框和密集霓虹管；不以增加金属、雕纹或装饰数量作为提升质感的方法。
- 机台、彩球、券和礼盒优先使用同系列高质量立体素材。交互球体、旋钮、光效与机身分层，不能以整张海报覆盖全部交互。
- 功能性小图标保持线性家族；主体和里程碑不能退化成一排图标或emoji。

## 页面层级与装置比例

- 本次专家页上方已恢复的服务介绍区保持原样，包括标题、光球、介绍、标签、按钮和数据。用户最新要求只压缩下方活动区，并尽量让上下两部分在首屏可见；不能改变上方内容、间距或比例来达成目标。
- 首屏空间必须扣除实际导航、安全区和既有介绍区后再计算。活动首页采用紧凑展示入口，把重复标题、奖品列举、余额、累计摘要和完整进度收进原活动弹层；短屏剩余空间不足时保留可用滚动，不裁切内容，不缩小文字和点击热区，也不宣称所有设备都能一屏展示。
- 展示机台保持简单完整的轮廓与协调比例。优先参考最新的圆润现代机台，不沿用早期参考中的冗长结构或繁复机械层次。
- 首页只做展示入口时，采用与既有深靛页面连续的轻容器、薄边界和局部柔光，保持一个清晰的活动主操作；选奖池、单抽/五连抽和完整累计进度进入活动弹层。排行榜、规则采用紧凑入口，不再各占一张大卡。
- AI专鉴卡是否保留完整进度服从当次用户选择，不能自动套用首页的收起方式。参与品类和重复规则不要在每处占空间。

## 有质感的奖励进度

- 使用宽、有填充厚度的连续轨道，当前完成位置明确，实际累计数与标记对齐。不能只用细线串起相同图标方块。
- 普通节点使用立体券、胶囊或小礼盒；高级节点用清晰的暖金色、通透高光与适度突出的形体。保持现代简洁的系列感，不借用机台已排除的宝石镶嵌或复古装饰。具体发券间隔由活动规则决定。
- 节点属于同一系列，通过材质、细节和光效变化建立节奏；外观不能暗示未定义的新奖励。文字仍标明奖励种类与里程碑。
- 未达到、当前目标、已获得三种状态有可辨的形态与文字。已获得节点可开启、点亮或打勾，不能只降低整体透明度。
- 长进度按实际累计数定位并支持回看历史。普通和高级到达动效有明确差别，高级可以有展开、光束和粒子层次，避免闪屏及阻断操作。

## 验收

实际页面截图需同时显示上下两区，检查是否属于同一套产品：既有专家区保持原样；活动区底色、光源、按钮与页面连续；机台圆润简洁、材质清楚、玻璃通透；首页文案与入口紧凑。检查390×844、320和430宽度及短屏，记录首屏可见范围；高度不足时允许正常滚动，文字与关键操作不能裁切。

素材漂亮不代表页面通过，必须检查运行画面和弹层切换。新生成图片及其页面排布仍是待用户检视的实现，不得写成“用户已认可”的视觉基线。

支持减少动态效果。发券、扣券和结果保存由业务状态控制，不能以动画次数充当业务次数。定向演示结果不得污染正常概率逻辑或历史数据。
