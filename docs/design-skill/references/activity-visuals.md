# 活动视觉：鲜艳清透、现代材质

适用于图灵鉴X的抽奖装置、活动入口、奖励反馈与里程碑。来源：用户2026-10-20针对专鉴扭蛋活动的多轮纠正，以当日最新要求为准。深靛承担产品背景，活动主体采用清透、明亮的现代材质；具体页面结构见 [最新活动基线](product-baseline.md)。

## 色彩与材质

- 本次扭蛋机采用圆润白色或冰蓝色塑料、陶瓷质感外壳，形体简单、圆角连续，保留足够留白。玻璃球舱清透，内部奖品可辨，光源与接触阴影统一。
- 电光蓝、亮紫、玫紫用于按钮、彩球和少量装饰；青蓝用于清透高光，暖金区分高级奖励。鲜艳通过饱和点缀与干净的亮暗关系体现，不能给所有颜色罩灰，也不把整个机台涂成浓重的紫色。
- 活动点缀色起点：电光蓝 `#315BFF`、亮紫 `#853BFF`、玫紫 `#F03DDB`、青蓝 `#48E8FF`、亮金 `#FFD36B`。这些变量不是机身大面积铺色要求，以实际合成截图为准调整。
- 高级感来自材质细节、比例与留白。本次机台不使用宝石镶嵌、羽翼、复古机甲、繁复金属边框和密集霓虹管；不以增加金属、雕纹或装饰数量作为提升质感的方法。
- 机台、彩球、券和礼盒优先使用同系列高质量立体素材。交互球体、旋钮、光效与机身分层，不能以整张海报覆盖全部交互。
- 功能性小图标保持线性家族；主体和里程碑不能退化成一排图标或emoji。

## 页面层级与装置比例

- 本次专家页恢复原有约半屏的服务介绍区。活动入口位于其后，允许正常纵向滚动；不能为了把完整机台塞进首屏再次删除、折叠或过度压缩已要求恢复的介绍。
- “主要信息与完整机台一屏可见”仅在用户当次明确要求时适用。此时先减少重复内容与装饰，按导航和安全区规划高度；保留用户明确要求的内容，不通过缩小文字、按钮硬塞，也不自行删除服务介绍。
- 展示机台保持简单完整的轮廓与协调比例。优先参考最新的圆润现代机台，不沿用早期参考中的冗长结构或繁复机械层次。
- 首页只做展示入口时，保持一个清晰的活动主操作；选奖池、单抽/五连抽和完整累计进度进入活动弹层。排行榜、规则采用小而醒目的入口，不再各占一张大卡。
- AI专鉴卡是否保留完整进度服从当次用户选择，不能自动套用首页的收起方式。参与品类和重复规则不要在每处占空间。

## 有质感的奖励进度

- 使用宽、有填充厚度的连续轨道，当前完成位置明确，实际累计数与标记对齐。不能只用细线串起相同图标方块。
- 普通节点使用立体券、胶囊或小礼盒；高级节点用清晰的暖金色、通透高光与适度突出的形体。保持现代简洁的系列感，不借用机台已排除的宝石镶嵌或复古装饰。具体发券间隔由活动规则决定。
- 节点属于同一系列，通过材质、细节和光效变化建立节奏；外观不能暗示未定义的新奖励。文字仍标明奖励种类与里程碑。
- 未达到、当前目标、已获得三种状态有可辨的形态与文字。已获得节点可开启、点亮或打勾，不能只降低整体透明度。
- 长进度按实际累计数定位并支持回看历史。普通和高级到达动效有明确差别，高级可以有展开、光束和粒子层次，避免闪屏及阻断操作。

## 验收

实际页面截图与用户最新参考图并排检查：机台圆润简洁、白色或冰蓝色材质清楚、玻璃通透、饱和点缀鲜明，恢复的专家介绍区完整保留，标题与榜单不过度占空间。检查390×844、320和430宽度及短屏；允许按当前布局滚动，文字与关键操作不能裁切。

素材漂亮不代表页面通过，必须检查运行画面和弹层切换。新生成图片及其页面排布仍是待用户检视的实现，不得写成“用户已认可”的视觉基线。

支持减少动态效果。发券、扣券和结果保存由业务状态控制，不能以动画次数充当业务次数。定向演示结果不得污染正常概率逻辑或历史数据。
