# 活动视觉：鲜艳、立体、首屏聚焦

适用于图灵鉴X的抽奖装置、活动入口、奖励反馈与里程碑。来源：用户2026-10-20针对专鉴扭蛋活动的明确纠正。深靛承担背景，活动主体要有鲜明的色彩与材质。

## 色彩与材质

- 装置和奖励采用高饱和电光蓝、亮紫、玫紫；青蓝作冷色高光，暖金区分高级奖励。避免给所有颜色罩灰或统一降低透明度。
- 活动色起点：电光蓝 `#315BFF`、亮紫 `#853BFF`、玫紫 `#F03DDB`、青蓝 `#48E8FF`、亮金 `#FFD36B`。以实际合成截图为准调整。
- 玻璃球舱清透、奖品可辨；金属外壳有明确亮边、暗面、接触阴影和统一光源。亮眼靠饱和度、明暗反差与材质，不靠全屏雾状泛光。
- 机台、彩球、券、礼盒、晶体等主体优先使用高质量统一素材。交互球体、旋钮、光效与机身分层，不能以整张海报覆盖全部交互。
- 功能性小图标保持线性家族；主体和里程碑不能退化成一排图标或emoji。

## 首屏与装置比例

- 用户要求一屏展示时，先删除重复标题、长介绍、冗余数据和大入口卡，给核心装置及操作留空间。不要缩小文字和按钮硬塞。
- 按实际视口减去导航、安全区规划高度；主要信息和完整机台在基准手机首屏可见。验证390×844，并检查320、430宽度及短屏。短屏先减装饰与间距，关键操作不能裁切。
- 展示机台使用紧凑、较宽的比例。参考图的机械层次和材质可保留，不照搬过长机身。
- 首页只做展示入口时，保持一个清晰的活动主操作；选奖池、单抽/五连抽和完整累计进度进入活动弹层。排行榜、规则采用小而醒目的入口，不再各占一张大卡。
- AI专鉴卡是否保留完整进度服从当次用户选择，不能自动套用首页的收起方式。参与品类和重复规则不要在每处占空间。

## 有质感的奖励进度

- 使用宽、有填充厚度的连续轨道，当前完成位置明确，实际累计数与标记对齐。不能只用细线串起相同图标方块。
- 普通节点使用立体券、胶囊或小礼盒；高级节点用更鲜明的金色或棱镜材质及更突出的形体。具体发券间隔由活动规则决定。
- 节点属于同一系列，通过材质、细节和光效变化建立节奏；外观不能暗示未定义的新奖励。文字仍标明奖励种类与里程碑。
- 未达到、当前目标、已获得三种状态有可辨的形态与文字。已获得节点可开启、点亮或打勾，不能只降低整体透明度。
- 长进度按实际累计数定位并支持回看历史。普通和高级到达动效有明确差别，高级可以有展开、光束和粒子层次，避免闪屏及阻断操作。

## 验收

实际页面截图与用户参考图并排检查：主体鲜艳清透、奖励有形体、完整装置位于首屏、标题和榜单不抢高度、文字清楚。素材漂亮不代表页面通过，必须检查运行画面和弹层切换。

支持减少动态效果。发券、扣券和结果保存由业务状态控制，不能以动画次数充当业务次数。定向演示结果不得污染正常概率逻辑或历史数据。
