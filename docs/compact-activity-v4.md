# 专家活动入口第四轮改版

日期：2026-10-20。依据用户对线上第三版的截图反馈。本文件记录本轮实现方向和验收边界，不表示用户已经认可新素材或页面效果。

## 上一版的问题

- **参考图配色被误当成品牌方向。** 用户提供现代圆润扭蛋机作为造型参照，上一版却把瓷白、冰蓝与宝蓝整体移植到深靛专家页。机台的色温、亮度和塑料高光与上方柔和蓝紫光球不一致，形成上下两个产品的观感。
- **活动容器进一步放大了割裂。** 大片高饱和紫色、粗亮边框、粉紫按钮和厚重彩色阴影同时竞争视觉中心。材质没有统一，装饰密度也超过上方专家区。
- **入口承担了过多内容。** 活动眉题、大标题、副标题、榜单块、完整大机台、奖品清单、长按钮、赠券提醒和两项数据纵向堆叠，产生了接近一个整屏的第二张页面。
- **先前规范含有未经确认的推断。** “白色或冰蓝色机台”并非用户明确指定的品牌规则。本轮已在设计 Skill 中更正：提取参考图形体与现代材质，配色必须回到实际页面上下文。

## 本轮处理

- 上方原专家区保持原样，包括标题、光球、说明、标签、立即鉴别按钮、三项数据以及它们的样式与布局。
- 活动首页改为紧凑横向展示入口。文字与操作集中一侧，另一侧保留完整小型机台及可辨奖品，减少垂直堆叠。
- 容器延续深靛底色、细边界和局部紫色柔光。机台调整为浅紫缎面陶瓷与通透紫色玻璃，按钮延续既有品牌渐变。
- 删除首页重复标题、长引导文案、奖品品牌清单和余额、累计数据块。领取状态与有效期用短句表达；完整余额、进度、单抽和五连抽仍在同一活动弹层内查看和操作。
- 排行榜与规则保留紧凑入口；AI结果专鉴卡的完整进度不受首页精简影响。
- 活动业务规则、普通与高级券、首次引导券逻辑、抽奖次数和榜单计数不随视觉改版改变。

## 首屏验收边界

用户要求“不更改上面的部分”，因此可用高度取决于实际导航、安全区及既有专家区。以390×844为主要验证视口，同时检查320和430宽度、375×568短屏及实际桌面预览。

验收时记录活动入口高度、完整专家区高度和首屏可见范围，不能仅根据CSS目标尺寸宣称已经一屏展示。若短屏空间不足，应保留正常纵向滚动，不能裁掉内容、隐藏关键操作、压缩上方专家区或把文字和热区缩小到难以使用。

实测活动主卡为159–160px，320×667、390×844和430×932均可首屏完整展示。375×568极短屏保留约97px自然滚动。具体运行尺寸与截图记录在项目的 `design-qa.md`。新机身生成信息及提示词见 [品牌统一机身素材](brand-machine-v4-assets.md)。
