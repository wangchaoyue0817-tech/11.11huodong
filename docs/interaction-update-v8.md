# 双11扭蛋交互调整 · v8

- 活动期间，普通券与高级券均无可用余额时，专家页扭蛋弹窗以「去专鉴赢抽奖券」主按钮替代禁用抽奖按钮，展示真实累计进度对应的下一张券及所差单数。点击直接打开现有选择鉴定品类流程。
- 任一奖池仍有可用券时保留选池和单抽、五连抽。活动前后不出现继续鉴定赢券的引导。
- 删除次日场景的提醒弹窗、提示数据和专用样式；每日赠券静默自动刷新，首次新手体验引导保留。
- 抽奖操作的视觉层级以可用状态为准：可用的单抽与五连抽均用明亮蓝紫渐变、白字、细高光边和轻光晕；不可用按钮用低饱和靛紫实底，无光晕。状态通过实际 disabled 属性控制。
- 双11抽奖页及操作弹窗根据当前奖池显示所差券数，活动前后显示活动状态；抽奖页运行中两按钮锁定并显示「正在开奖」。卡牌单抽与五连抽同步可用/不可用视觉，保留原布局和历史活动逻辑。

## 验证

- 完整测试 277 项通过，包含两池隔离、0/1/4/5 张券、里程碑前后、活动前后、末张券消耗、跨日自动赠券、首次引导与真实导航。
- 本机浏览器检查 320 × 667、390 × 844、430 × 932，无横向溢出。
- 实际点击无券主按钮进入品类半弹层；抽奖过程中按钮正确锁定。
